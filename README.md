# Build with intention.

I’m **Seven Du**. I build small, focused tools and explore how languages and runtimes work.

Most of my open-source work lives in the Dart ecosystem: compilers, WebAssembly, native integration, and reactivity.

[Website ↗](https://medz.dev/) · [All projects](https://medz.dev/projects/) · [Résumé](https://medz.dev/resume/) · [Email](mailto:hi@medz.dev)

### What I’m building

- **[dartc](https://github.com/medz/dartc)** — A native Dart compiler, written entirely in Dart.
- **[wasd](https://github.com/medz/wasd)** — A WebAssembly runtime for Dart and Flutter.
- **[napi](https://github.com/medz/napi)** — Build Node.js extensions in Dart, with native and WebAssembly targets.
- **[Alien Signals](https://github.com/medz/alien-signals-dart)** — Fine-grained reactivity for Dart and Flutter.
